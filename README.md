Repo of duplicate skill folders that are uploaded to [clawHub skills](https://clawhub.ai/skills?sort=downloads) but still available to view on GitHub.

Each skill folder is self-contained, with a `SKILL.md` file and optional supporting resources such as reference documents, scripts, assets, and templates. Each skill utilizes conventions from [Agent skills specification](https://agentskills.io/specification).

## Skill Structure

Skills live in the category folders listed in [categories.json](categories.json). A new skill starts at the repo root, where it is listed as uncategorized until it moves into a category. Every skill follows the standard Agent Skills layout:

```
<category>/
└── <skill-name>/
    ├── SKILL.md            # Required - skill definition and instructions
    ├── references/         # Optional - documentation the agent reads
    ├── scripts/            # Optional - executable automation code
    ├── assets/             # Optional - static files used as-is
    └── templates/          # Optional - starter code scaffolds
```

## Quickstart

```bash
# Add a skill folder at the repo root to the Skills table (listed as uncategorized)
node scripts/newSkill.js demo-skill "Short description."

# Move the skill into a category from categories.json
node scripts/categorize.js demo-skill coding

# Print where a skill lives
node scripts/skillPath.js demo-skill

# Check folders, categories, links, and the Skills table
node scripts/auditSkills.js
```

## Adding a New Skill

1. Create a new folder at the repo root with a lowercase, hyphenated name
2. Add a `SKILL.md` file with the required YAML frontmatter (`name` and `description`)
3. Add optional directories (`references/`, `scripts/`, `assets/`, `templates/`) as needed
4. Update this README with the new skill entry, linking to repo folder and skill on [ClawHub](https://clawhub.ai/)
   - Run `node scripts/newSkill.js <skillName> [description]`
   - The script sorts the table, moves each letter's `<span id>` anchor to the first skill starting with that letter, and rebuilds the letter nav above the table
5. Move the skill into a category
   - Run `node scripts/categorize.js <skillName> [skillName...] <category>`
   - The script moves the folder with `git mv`, then updates the skill's repo link and Category column
   - After editing the table by hand or moving a folder yourself, run `node scripts/sortTable.js` to resync the table
6. Run `node scripts/auditSkills.js` to confirm the folders, categories, links, and table agree

To add a category, add its folder name and a one-line description to [categories.json](categories.json).
